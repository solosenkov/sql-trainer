# SQL-тренажёр QArtel

Продакшн: https://sql-trainer-2ia.pages.dev/ · Cloudflare Pages `sql-trainer`, D1 `sql-trainer-db`.

45 заданий на SQLite, три уровня, подсказки и проверка результата. Старые 30 заданий сохранены, новые — ID 31–45. Раздел **Запросы** позволяет выполнять свободный SELECT / WITH на тех же шести учебных таблицах (до 100 строк). Команды изменения данных и рекурсия отклоняются.

## Локально

```sh
python3 db/seed.py
python3 server.py --port 8000
```

Локальная и облачная учебные базы создаются из `db/schema.sql` и `db/seed.py`. Новые задания также описаны в `db/additional-exercises.json`. Прогресс сохраняется только в браузере. ID существующих заданий не изменены. Прямая ссылка на задание: `/#exercise-31`, свободный редактор: `/#queries`.

## Проверка

```sh
node --test tests/worker.test.mjs
```

Worker проверяется с адаптером настоящего SQLite: все 45 эталонов, альтернативное правильное решение, неверный порядок, пустой результат, ограничения вывода и запрет изменений. Облачный worker использует D1 API `raw({columnNames:true})`, поэтому столбцы известны даже для пустого результата.

## Деплой

```sh
wrangler whoami
wrangler pages deploy frontend --project-name sql-trainer --branch main
```

`wrangler.toml` фиксирует исходный проект и биндинг DB. Деплой из main обновляет production-домен. Этот Pages-проект создан прямой загрузкой: GitHub хранит исходники, но сам по себе push не запускает Cloudflare-деплой. Для публикации используется авторизованный Wrangler на машине владельца.

Миграция новых заданий выполняется **один раз**:

```sh
wrangler d1 execute sql-trainer-db --remote --file db/migrations/001-add-practice.sql
```

Нельзя запускать `db/import-d1.py` на действующей базе ради обычного обновления: это старый способ полной загрузки. Перед миграциями экспортируйте резервную копию D1; не коммитьте бэкапы, токены и `.wrangler/`.
